# V3.0 — Bật VPN vẫn báo lỗi thì sửa ở đâu

Đọc đúng thứ tự, đừng nhảy bước. Mục đích: tách lỗi **do module** hay **do cấu hình của máy**.

## Bước 0 — Trạng thái sạch

1. Tắt VPN.
2. Vào tab **Module**, xoá **hết** module có chữ `Spotify`
   (2.5, 2.6, 2.7, cả module của người khác). Hai module cùng sửa một URL là đè nhau.
3. Vào tab **Cấu hình (Config)**, xem file `.conf` đang dùng tên gì — ghi lại tên.
4. Bật VPN khi **chưa có module Spotify nào**.

| Kết quả | Nghĩa là | Đi tiếp |
|---|---|---|
| VPN lên bình thường | Lỗi nằm ở module | Sang bước 1 |
| Vẫn báo lỗi | Lỗi nằm ở `.conf` hoặc file rule | Sang bước 2 |

## Bước 1 — Cài tầng nhẹ nhất

Dán link, Add, **chỉ một module duy nhất**:

```
https://spotify-vn.web.zaka.live/spotify-vn-mini.module
```

- Lên được → cài tiếp `spotify-vn-lite.module` (xoá mini trước), rồi `spotify-vn-premium.module`.
- Báo lỗi → gửi ảnh chụp câu báo lỗi. Nếu MINI cũng lỗi mà không module thì OK,
  gần như chắc chắn `.conf` đang có dòng rule trùng tên hoặc sai cú pháp.

## Bước 2 — Soi `.conf` của mày

Mở file `.conf` đang dùng (tab Cấu hình → bấm vào file → Edit). Tìm và xử lý:

1. **Dòng có `AND,(` hoặc `PROTOCOL,UDP` hoặc `URL-REGEX`** → xoá cả dòng.
   Shadowrocket bản mới không nhận cú pháp này; gặp là báo lỗi và VPN không lên.
2. **Rule `[Rule]` trỏ tới file `.list` không tồn tại** (đổi tên, xoá, hoặc link 404)
   → VPN báo lỗi ngay khi bật. Mở link đó bằng trình duyệt kiểm tra.
3. **`[MITM] hostname` có dòng quá dài hoặc có `*= `** → cắt bớt, để mỗi host một dòng.
4. **Hai file cấu hình cùng tên** → Shadowrocket nạp cái cũ.

Sửa xong: tắt VPN, bật lại.

## Bước 3 — Nếu vẫn lỗi

Tạo một cấu hình trắng để đối chiếu:

1. Tab Cấu hình → dấu `+` → tạo file mới, không thêm rule nào.
2. Chọn file đó → bật VPN.

- File trắng mà vẫn báo lỗi → lỗi ở **ứng dụng hoặc máy** (certificate profile hỏng,
  DNS, hoặc bản Shadowrocket lỗi). Gỡ profile cũ trong Cài đặt iOS → Cài đặt chung →
  VPN & Quản lý thiết bị, cài lại, hoặc cập nhật app.
- File trắng OK, file cũ lỗi → quay lại bước 2, xoá dần từng nhóm rule để tìm dòng bẩn.

## Câu báo lỗi hay gặp

| Câu báo | Nghĩa | Sửa |
|---|---|---|
| `配置错误` / `Config error` | File cấu hình hoặc module sai cú pháp | Bước 2 |
| `发生错误` ngay khi gạt công tắc | Không parse được file | Bước 2 |
| VPN lên nhưng app không có mạng | MITM bật mà cert chưa trust | Cài đặt → Giới thiệu → Chứng nhận tin cậy chứng chỉ gốc → bật cho cert Shadowrocket |
| VPN lên, Spotify vẫn như cũ | Script chưa chạy | Kiểm tra đã bật MITM trong app, và module đã Add đúng |

## Nhắc lại giới hạn

- Ép cấp âm thanh chỉ đổi được URL mà app gọi. Server không có bản 320 cho tài khoản
  đó thì vẫn ra 96/160 — đó là server quyết.
- Chữ "Premium" trên hồ sơ nằm phần lớn trong app bundle, không qua mạng → proxy không sửa.
- Trang quản lý gói: đổi được nhãn/màu dữ liệu server trả, không tạo gói không tồn tại.
