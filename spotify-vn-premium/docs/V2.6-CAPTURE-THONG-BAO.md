# v2.6 — Bắt gói có THÔNG BÁO + kênh gửi dữ liệu về log

## 1. Vì sao các lần trước thất bại
File `.db` xuất từ Shadowrocket có 4 cột: `url | ua | result | type | created`.
**Không có body.** Nên mọi lần mày gửi log, tao chỉ đọc được URL —
ví dụ `storage-resolve/v2/files/audio/interactive/2/<hash>?product=0` —
và hoàn toàn không biết server trả gì trong đó.

v2.6 vá đúng chỗ đó bằng 2 script:

| Script | Loại | Việc |
|---|---|---|
| `scripts/capture.js` | http-response | đọc payload, nổi banner, gom 720 byte đầu (base64) vào hàng đợi |
| `scripts/drip.js` | http-request | cắt hàng đợi thành mẩu 660 ký tự, gắn vào query `zcap=0001.<base64url>` của request Spotify kế tiếp |

Server Spotify bỏ qua tham số lạ, request vẫn chạy; Shadowrocket ghi nguyên URL
(kèm `zcap=`) vào log `.db`. Xuất log gửi lại là tao đọc được **payload thật**.

Giải mã khi cần: `python3 tools/decode-log.py proxy-....db --raw`

## 2. Banner trông thế nào
```
[spot-vn] net-fortune
HTTP 200 · 412B · gom về log
160 96 q=HIGH
```
```
[spot-vn] product-state
HTTP 200 · 88B · gom về log
320 ✔ q=VERY_HIGH prod=premium premium×2
```

Quy ước:
- `320 ✔` — trong payload CÓ dấu hiệu file 320kbps/OGG_VORBIS_320.
- `160` / `96` — chỉ có bản thấp hơn.
- `q=` — giá trị quality tìm thấy (VERY_HIGH/HIGH/NORMAL/LOW).
- `prod=` — giá trị product/product_state.
- `premium×N` / `free×N` — số lần chuỗi xuất hiện.

Không thấy banner nào = MITM chưa bắt (thiếu cert, hoặc app đi HTTP/3 — module
đã chặn UDP sẵn).

## 3. Giới hạn thật, nói thẳng
- **320kbps + tải offline**: server cấp license và chọn file theo tier tài khoản.
  Nếu `net-fortune` chỉ trả 96/160 thì đó là quyết định phía server, sửa client
  không với tới.
- **Chữ "Premium" ở badge hồ sơ**: phần lớn chuỗi này nằm trong app bundle
  (Localizable.strings), không đi qua mạng → proxy không đổi được. Chỉ đổi được
  khi chuỗi đó nằm trong response JSON/protobuf (pam-view-service,
  premium-marketing) — script đã thử đổi sang "ToCam".
- **Trang quản lý gói**: dữ liệu thật do server trả (pam-view-service /
  open.spotify.com). Proxy chỉ đổi được nhãn/màu, không tạo ra gói không tồn tại.

## 4. Cài
1. Shadowrocket → dán `https://spotify-vn.web.zaka.live/spotify-vn-premium.module` → Add.
2. Gỡ module Spotify cũ (2 module cùng sửa sẽ đè nhau).
3. Tắt/bật VPN, mở Spotify → phải thấy `[spot-vn] CAPTURE ĐÃ CHẠY`.
4. Cài đặt → Chất lượng nội dung → bấm "Rất cao" → đọc banner.
5. Shadowrocket → Settings → Log → xuất `.db` → gửi lại.
